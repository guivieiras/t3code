# Preview workspace files

Open the file explorer from a thread to inspect files in that thread's workspace. Text and
Markdown files open in the source viewer, while supported media files open in a dedicated preview.

Audio previews use the system's native playback controls. T3 Code recognizes AAC, FLAC, M4A, MP3,
Ogg/Opus, WAV, and WebM audio files. Playback still depends on the codecs supported by your browser
or device.

The preview works through the connected environment, so the workspace does not need to be on the
same device as the client.

Other binary file types are not rendered as text. T3 Code identifies them as unsupported previews
instead of displaying unreadable contents.
